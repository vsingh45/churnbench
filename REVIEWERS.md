# For Reviewers: Tracing Every Number

A map from each empirical claim in the paper to the committed file or script
that backs it, and the exact command to recompute it. Every artifact listed
here is generated from committed source data by a committed script — nothing
in this file is hand-transcribed from the paper.

If a number in the paper doesn't match what its listed artifact currently
shows, that's a discrepancy worth reporting — see [Known discrepancies](#known-discrepancies)
below for the ones already found and not yet reconciled.

## Known discrepancies

Found while building this traceability set, not yet reconciled against the
paper text. Listed rather than silently corrected, since fixing the paper vs.
fixing the artifact are different actions and the choice belongs to the author.

1. **D+28 accuracy**: the paper may state 63.9%. The current, corrected
   `results/d28_matched_baseline_full.json` (post-retry, 4 previously-undetected
   permanent failures repaired) shows **65.0%**. 63.9% is the pre-retry
   figure, preserved for audit in
   `results/d28_matched_baseline_pre_retry_backup_full.json`.

2. **D+14 is not config-matched to D+1/D+28**: its committed baseline
   (`results/d14_baseline_full.json`) runs at `git_sha=6ba168e`, which predates
   the `enable_thinking=False` fix — reasoning is ON for this window, OFF for
   the other two. This was a deliberate choice at retry time (a pinned git
   worktree was used specifically so the 5 retried tasks matched the other 175
   *already-run* tasks in that file), but it means Table III's three rows are
   not all under one model configuration. Flagged per-row in
   `table3_sweep.csv`'s `reasoning_mode_note` column.

3. **"Five runs affected by interface instability"**: `run_provenance.csv`
   currently shows **4** distinct experiments with permanent failures at some
   point (D+14 baseline, D+1 ablation, D+28 ablation, D+28 matched baseline) —
   8 rows total counting each one's paired pre-retry backup separately, but 4
   underlying runs. If the paper's "five" includes a run not represented here,
   say which one and it can be added; if not, five should become four.
